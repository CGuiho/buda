# Curation

Split oversized concepts, reconcile only confirmed duplicates, improve
descriptions and links, and deprecate rather than erase linked knowledge.
Preserve provenance and history. qmd similarity returned through Buda is a lead,
not proof of duplication and never permission for an automatic merge.
